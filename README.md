## Laboratory 0

MiniShop calculates order totals with standard delivery, express delivery,
or free pickup. The code demonstrates SRP, OCP, and DIP.

Run it from the repository root:

```powershell
python Lab0/main.py
```

## Laboratory 1

The first laboratory builds on the same MiniShop project and demonstrates
the Builder, Factory Method, and Prototype patterns.

Run it from the repository root:

```powershell
python Lab1/main.py
```

Each laboratory has its own report and runnable program.
The `Example/` folder is excluded from this repository.
